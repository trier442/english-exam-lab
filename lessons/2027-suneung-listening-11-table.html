이 강에서 익힐 것

도표 문제는 모든 정보를 메모하기보다 조건이 나올 때마다 후보를 지우는 방식이 효율적입니다. 가격, 날짜, 기능, 거리 중 어떤 조건이 우선인지 구분하세요.

핵심 판단식조건 듣기 → 후보 제거 → 최종 확인

1단계

2

2단계

조건이 들릴 때 맞지 않는 후보를 지웁니다.

3

3단계

마지막 선호·결정 표현으로 남은 후보를 확인합니다.

1조건을 메모만 하고 후보를 지우지 않음도표의 열과 후보 차이를 미리 봅니다.
2선호 조건과 필수 조건을 같은 비중으로 처리조건이 들릴 때 맞지 않는 후보를 지웁니다.
3마지막에 바뀐 선택을 놓침마지막 선호·결정 표현으로 남은 후보를 확인합니다.

문제 1

두 사람이 선택할 요금제는?

선택지를 고른 뒤 정답을 확인하세요.

정답 3번 · Plan C

200GB 이상, 4인 공유, 오프라인 사용 가능, 월 $15 미만 조건을 모두 만족하는 것은 Plan C입니다.

문제 2

여자가 중요하다고 언급한 조건이 아닌 것은?

선택지를 고른 뒤 정답을 확인하세요.

정답 5번

1TB 이상은 요구하지 않았고, 200GB 이상이면 충분하다고 했습니다.
